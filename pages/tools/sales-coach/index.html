Setup Guide

"This is your spotter. You record the call, it scores every step of the Repeatable Sale — with your exact words as proof. No fluff. No guessing. Just the two or three things to fix next time." — Simon Severino 🐬🐯🌴

Score any sales call against the 8 Steps of the Repeatable Sale. Every score is tied to a verbatim quote from your transcript. Setup takes 15 minutes. After that — one command, and your coach is live.

15 min setup Mac & Windows Works with Granola or any transcript
No Terminal? No Problem.

Paste the coach.md contents and your transcript directly into claude.ai for an identical report — no install needed. This guide covers both paths.

Step 1 of 5
1
Install Node.js First

Go to nodejs.org and download the LTS version (the button on the left — it says "Recommended For Most Users"). Run the installer. The defaults are correct — just click through.

After install: close your terminal window and open a fresh one. This is the most common reason Step 2 fails — Node.js won't be recognised until the terminal restarts.

Verify it worked:

Terminal / Command Prompt 
node --version

You should see something like v20.14.0. Any v18 or higher is fine. If you see nothing, the terminal wasn't restarted — close it and try again.

Step 2 of 5
2
Install Claude Code

In your fresh terminal window, run:

Terminal / Command Prompt 
npm install -g @anthropic-ai/claude-code

Confirm the install:

Terminal / Command Prompt 
claude --version
Important distinction: claude --version only confirms the install. It does not launch Claude Code. To actually open and use it, you type claude with no flags — which you'll do in Step 5.
Step 3 of 5
3
Create the State Folder

The Sales Coach logs your scoring history to ~/.claude/state/. Without this folder, history logging fails silently — you'll get scores but no record over time.

Mac Terminal 
mkdir -p ~/.claude/state && mkdir -p ~/.claude/commands

Press Win+R, type cmd, press Enter to open Command Prompt:

Windows Command Prompt 
mkdir %USERPROFILE%\.claude\state
mkdir %USERPROFILE%\.claude\commands
Step 4 of 5
4
Install the Coach Plugin

Download coach.md and place it inside the ~/.claude/commands/ folder you just created. That's the only file the plugin needs.

Download coach.md:

Download coach.md ↓

Move the downloaded file with this command (replace ~/Downloads/coach.md if you saved it elsewhere):

Mac Terminal 
cp ~/Downloads/coach.md ~/.claude/commands/coach.md
Prefer nano? Run nano ~/.claude/commands/coach.md, paste the file contents, then Ctrl+O → Enter → Ctrl+X to save.

Move the downloaded file, or create it fresh in Notepad:

Windows Command Prompt 
copy %USERPROFILE%\Downloads\coach.md %USERPROFILE%\.claude\commands\coach.md
Notepad trap: If you create the file in Notepad, go to File → Save As and change "Save as type" to All Files (*.*) before saving. Otherwise Notepad adds a hidden .txt extension and the plugin won't load.
Step 5 of 5
5
First Launch & Login

Type claude in your terminal — no flags, nothing else. This is what actually opens Claude Code.

Terminal / Command Prompt 
claude

First-launch sequence — here's exactly what you'll see:

What you seeWhat to do
Text-style welcome screen Claude Code is open. You're inside the tool.
Login method menu Choose Claude subscription (claude.ai Pro/Team) or Anthropic Console (API key).
Browser window opens Log in to your Anthropic account. The page will confirm you're authenticated and close.
Terminal shows prompt > You're logged in. Claude Code is ready.

Set your model once — right now:

Model selection happens inside a running session, not during setup. After login, type:

Inside Claude Code 
/model sonnet

This saves permanently. You won't need to set it again. Check what's active any time with /status.

Why Sonnet, not Opus? Sonnet is fast, cost-efficient, and more than capable for scoring a sales call. Opus is overkill here — slower and more expensive for the same result on this task.
✅ Setup complete. Everything below is how you actually use it — choose your transcript path.
Using the Plugin

Choose Your Transcript Path

How are you getting your transcript into the coach? Pick one:

🎙️
Path A — Granola
Granola auto-captures your calls and feeds transcripts directly to Claude Code. Fastest for recurring use.
📄
Path B — Local File
You have a transcript as a .md or .txt file. No Granola required — works with any recording tool.

Path A: Granola Setup

Granola transcribes your calls automatically and connects to Claude Code via MCP. Set up once — then it's one command after every call.

1. Install Granola — download from granola.ai

2. Connect Granola to Claude Code — follow the MCP setup at granola.ai/docs/mcp

3. After any call, open Claude Code and type:

Inside Claude Code 
/coach

Granola pulls the latest transcript automatically. Your coach returns a score, verbatim evidence for each of the 8 Steps, and your top 3 fixes.

Transcript not showing up? Make sure Granola was running during the call and the MCP connection is active. See Troubleshooting below.

Path B: Local Transcript File

Save any transcript as a .md or .txt file and run the coach on it directly. Works with Otter, Fireflies, Zoom transcripts, or anything you can export as text.

Suggested folder — create once:

Mac Terminal 
mkdir -p ~/transcripts

Save transcripts like: ~/transcripts/acme-call-2026-06-22.md

Run the coach:

Inside Claude Code 
/coach file ~/transcripts/acme-call-2026-06-22.md
🐬 Drag-and-drop tip: Open Finder, navigate to your transcript, drag the file into the Terminal window. The full path is pasted automatically — no typing required.
Windows Command Prompt 
mkdir %USERPROFILE%\transcripts

Save transcripts like: C:\Users\YourName\transcripts\acme-call-2026-06-22.md

Run the coach:

Inside Claude Code 
/coach file C:\Users\YourName\transcripts\acme-call-2026-06-22.md
Windows path tip: Hold Shift and right-click your file → "Copy as path." Paste it directly into the command above.

Troubleshooting

Something Not Working?

Click any issue below to see the fix.

"command not found: npm" when installing Claude Code

Node.js isn't installed, or you didn't restart Terminal after install.

Fix: Go to nodejs.org → download LTS → run installer → close Terminal completely → open a fresh window → run node --version to confirm → then retry npm.

"command not found: claude" after the npm install

npm installed Claude Code but your terminal's PATH doesn't include npm's global bin folder yet.

Fix: Close and reopen Terminal. If it still fails, run npm config get prefix — the result is the folder where the binary lives. Add /that-folder/bin to your PATH.

I ran "claude --version" and nothing opened

claude --version only prints the version number. It does not launch the tool.

Fix: Type claude (nothing else) and press Enter. That opens the interactive session.

Claude Code opened but I don't know where to type

Claude Code runs as a text interface inside your terminal window. After the login screen, you'll see a prompt — usually >.

Fix: Click inside the terminal and type your command (e.g. /coach). Press Enter to run it.

I don't know which model is active / I want to change it

Run /status inside Claude Code to see the current model. To change: type /model sonnet (recommended) or /model opus. The setting persists between sessions.

"coach.md not found" when I type /coach

The plugin file isn't in the right folder.

Mac fix: Run ls ~/.claude/commands/ — you should see coach.md listed. If not, redo Step 4.

Windows fix: Open File Explorer → navigate to %USERPROFILE%\.claude\commands\ → confirm coach.md is there (not coach.md.txt).

"File not found" using /coach file <path> (Path B)

The path is wrong, the file has a different name, or you're using forward slashes on Windows.

Mac: Drag the file from Finder into Terminal — the correct path is pasted automatically.

Windows: Hold Shift → right-click the file → "Copy as path" → paste into the command. Use backslashes: C:\Users\YourName\transcripts\file.md

Granola transcript isn't being picked up by /coach

Either the MCP connection isn't active, or Granola didn't record the call.

Fix: Check your MCP connection at granola.ai/docs/mcp. Make sure Granola was running during the call and the meeting appears in Granola. If the transcript isn't in Granola, switch to Path B: export it as a .txt file and use /coach file <path>.

Windows: Notepad added ".txt" to my coach.md file

Notepad adds a hidden .txt extension unless you change "Save as type" to All Files. The result is coach.md.txt — which the plugin can't find.

Fix: In File Explorer, go to View → Show → File name extensions. Find coach.md.txt and rename it to coach.md.
